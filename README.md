# NovaShop — Frontend Fix & Redesign

A frontend repair and redesign project focused on improving the user interface, responsiveness, and overall user experience of an e-commerce website.

## Overview

NovaShop is a frontend project built to demonstrate practical skills in fixing UI issues, improving existing layouts, and creating a modern and responsive e-commerce experience.

## Features

- Modern and clean user interface.
- Responsive design for different screen sizes.
- Mobile navigation menu.
- Product showcase section.
- About and Contact sections.
- Contact success page.
- Improved layout and visual consistency.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Netlify (Deployment)
